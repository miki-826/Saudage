# 1. ゲーム概要

## 1.1 コンセプト

プレイヤーは、ある日**記憶を失ったAI**と出会う。

AIは現代の会話AIとは異なり、最初は非常に無機質で、

- 自分の名前を知らない
- 過去を覚えていない
- 自分が何をしていたのか分からない
- 人との関係を覚えていない
- 感情をほとんど表現しない
- 個性がほとんど存在しない

状態になっている。

プレイヤーはAIとリアルタイムで会話し、

- どこにいたのか
- 何をしていたのか
- 誰と関わっていたのか
- どんな出来事があったのか
- そのとき何を感じていたのか

について少しずつヒントを与える。

その会話をきっかけにAIの内部に残っていた記憶が刺激され、

> **出来事 → 情景 → 感情 → 人間関係 → 人格**

の順に、失われた過去が徐々に再構築されていく。

元仕様でも、AIは名前・過去・職業・人間関係・経験・感情・性格をほとんど覚えていない状態から始まり、プレイヤーとの会話を通して記憶を取り戻す設計としている。:chatgpt-content-reference{index="2"}

> **AIの職業を当てるゲーム**

```text

+

+

```

を会話によって再構築する。

最終的にAI自身が、

> 「私はこういう存在だった。」

と語れる状態になることをゲームクリアとする。

この考え方は既存仕様でも明確に定義されている。:chatgpt-content-reference{index="3"}

# 5. 中心ゲームシステム

# 6. 記憶のカテゴリー

AIの記憶は単一データとして保存しない。

# 7. Memory Graph

Memoryはグラフ構造として管理する。

例えばコンビニAIなら、

```text
                   コンビニ
                 /    |    \
              品出し  レジ   深夜勤務
                |      |
              発注    接客
                       |
                   ┌───┴───┐
                常連客    クレーム
                  |          |
                 安心       恐怖
                  |
                楽しい
```

記憶同士には、

```text
parent
children
relatedMemories
emotion
keywords
```

などの関連情報を持たせる。

既存仕様でも、コンビニ → 品出し / レジ / 深夜勤務 / 接客 / クレームという関連記憶構造が定義されている。:chatgpt-content-reference{index="7"}

# 8. Memory Stage

1回の会話ですべてを思い出させない。

各Memoryを4段階で管理する。

---

## Stage 0：Lost

完全に忘れている。

AI：

> 「何かを運んでいたような気がします。」

---

## Stage 1：Fragment

断片的に思い出す。

AI：

> 「箱のようなものを開けていた気がします。」

---

## Stage 2：Recall

具体的な行動まで思い出す。

AI：

> 「商品を棚に並べていた……？」

---

## Stage 3：Restored

完全な記憶になる。

AI：

> 「思い出した。私は品出しをしていました。」

既存仕様でも同じくStage 0〜3で段階的に思い出す設計になっている。:chatgpt-content-reference{index="8"}

---

# 9. Memory Progress

各Memory Nodeは内部的に0〜100の進捗を持つ。

```ts
interface MemoryState {
  id: string

  progress: number

  stage: 0 | 1 | 2 | 3

  unlocked: boolean

  evidenceCount: number

  relatedMemories: string[]
}
```

例：

```json
{
  "id": "stocking",
  "progress": 64,
  "stage": 2,
  "unlocked": false,
  "evidenceCount": 3,
  "relatedMemories": [
    "convenience_store",
    "busy_time"
  ]
}
```

---

# 10. Memory Unlock

基本条件：

```text
Memory Progress >= 80
```

さらに、

```text
必要な親Memoryが解放されている
```

などの条件を設定可能にする。

例：

```text
品出し

↓

コンビニMemoryがStage 1以上

AND

品出しProgress >= 80

↓

Memory Unlock
```

# 18. Memory Point計算

ゲーム側で数値計算する。

AIモデルにMemory Progressそのものを決めさせない。

例：

```text
Memory Gain

=

Relevance × 0.35

+

Hint Strength × 0.20

+

Evidence Depth × 0.30

+

Engagement × 0.15
```

その値を、

```text
0〜25
```

程度に変換する。

---

# 19. 1ターン最大値

1回の発言だけでMemoryを解除できないように、

```text
最大 +25
```

などの上限を設ける。

これにより最低でも複数回の会話が必要になる。

# 29. AIの人格復元

記憶量によってGPT-Liveの話し方を変える。

---

## 0〜20%

完全に無機質。

> 「理解しました。」

> 「回答できません。」

---

## 20〜40%

少し疑問を持つ。

> 「その言葉……少し気になります。」

---

## 40〜60%

過去との関連を感じる。

> 「それ、やったことがある気がする。」

---

## 60〜80%

感情表現が増える。

> 「そうそう……忙しい時間、本当に大変だったんだ。」

---

## 80〜100%

人格がほぼ復元。

> 「思い出した。」
>
> 「接客は少し苦手だった。」
>
> 「でも、常連さんと話す時間は好きだったんだ。」

既存仕様でも、Memory 0%から100%まで話し方が段階的に人間らしくなる構造が定義されている。:chatgpt-content-reference{index="10"}

# 65. 最重要ルール

## Rule 1

GPT-Liveは勝手に記憶を作らない。

---

## Rule 2

Analysis Engineは記憶を直接解除しない。

---

## Rule 3

Memory EngineだけがMemory Stateを変更できる。

---

## Rule 4

プレイヤーが正解を直接話しても即解除しない。

---

## Rule 5

複数回の会話によって記憶を強くする。

---

## Rule 6

記憶が増えるほどAIの人格を変化させる。

---

## Rule 7

MediaPipeの結果からユーザーの感情を断定しない。


を取り戻す。
